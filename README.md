# HuddleBoard - Marketing Website

A responsive, modern HTML/CSS marketing website for HuddleBoard, a SaaS product for virtual whiteboards and remote team collaboration.

## 🚀 Project Overview

**Product**: HuddleBoard  
**Tagline**: "Virtual Whiteboards for Remote Teams"  
**Description**: "Collaborate in real-time with sticky notes, mind maps, and drawing tools."

## 📁 File Structure

```
huddleboard/
├── index.html          # Home page with hero section and features preview
├── features.html       # Detailed features page with 6 key features
├── pricing.html        # Pricing page with 3 tiers (Free, Pro, Enterprise)
├── about.html          # About page with mission, values, and team bios
├── contact.html        # Contact page with form and contact information
├── login.html          # Clean login page with email/password form
├── signup.html         # Registration form with name, email, password
├── styles.css          # Main stylesheet with responsive design
├── script.js           # JavaScript for interactivity and mobile nav
└── README.md           # This file
```

## 🎨 Design Features

- **Clean SaaS-style UI** with modern aesthetics
- **Mobile-first responsive design** that works on all devices
- **Google Fonts (Inter)** for professional typography
- **Font Awesome icons** from CDN for visual elements
- **Subtle animations** including fade-ins and hover effects
- **Color palette**: Blue (#2563eb), white, and gray tones
- **Sticky navigation** with smooth scrolling and auto-hide
